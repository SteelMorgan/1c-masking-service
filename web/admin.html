Как получить файл стартовой настройки
  1. Попросите агента: Агент прочитает метаданные именно этой базы через маскирующий шлюз (данные не раскрываются) и сформирует файл masking-setup-<база>-<дата>.json с отчётом.
  2. Проверьте отчёт агента: что и почему он предлагает скрыть.
  3. Нажмите «Импортировать стартовую настройку» и выберите файл. Ничего не применится без вашего подтверждения.

    Это ослабление: поле лишается структурной маски. Правило «Не маскировать» по пути реквизита отменяет для поля структурные правила «Скрыть» по имени и типу, но словарь и шаблоны продолжают маскировать значения внутри поля. После активации его нужно будет подтвердить отдельно.
    
    
    Сервис пока не активирует версии с правилами «Секрет»: такая версия сохранится в черновике, но активация будет отклонена. Для скрытия используйте «Скрыть» — пароли, ключи и токены по имени поля уже вырезаются встроенными правилами.
